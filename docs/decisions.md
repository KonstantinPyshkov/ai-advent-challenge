# Зафиксированные решения

- Язык и сборка: Java 21 + Maven.
- Интерфейс: CLI; результаты — Markdown/CSV начиная со Дня 2.
- Локальный провайдер: Ollama, нативный `/api/chat`.
- Облачные провайдеры: архитектурно закладываются, но в первой версии не
  используются.
- День 1: отдельный минимальный модуль без `core`.
- День 1 использует самую маленькую модель: `qwen3.5:2b-mlx`.
- Модели по дням: 1 — 2B, 2 — 9B, 3 — 35B, 4 — 9B, 5 — 2B + 9B + 35B.
- Повторный запуск дня очищает только `logs/`, `reports/`, `conclusions/`.
- Метрики времени считаются только вокруг HTTP-запроса.
- Логи и отчёты — в папке дня.
- Ключи API — только env или `config/local.properties`; в git не попадают.
- Финальная версия — локальный коммит + тег `day-NN`.
- Push в этом проекте не выполняется.
