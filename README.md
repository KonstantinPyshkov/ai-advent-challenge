# AI Advent Challenge

Локальная лаборатория для заданий курса. Каждый день — отдельный модуль со своим
кодом, данными, промптами, документацией, логами и выводами.

Сейчас в проекте сделан **День 1**: минимальный клиент к локальному Ollama.
Он подключается к самой маленькой модели `qwen3.5:2b-mlx`, отправляет один
запрос и печатает ответ. Вся логика дня лежит в `days/01-minimal/`.

## Требования

- Java 21
- Maven
- [Ollama](https://ollama.com) с моделью `qwen3.5:2b-mlx`

```bash
ollama pull qwen3.5:2b-mlx
```

## Быстрый старт

```bash
mvn package
./scripts/run.sh "Привет! Кто ты?"
```

Или без скрипта:

```bash
java -jar days/01-minimal/target/day01.jar "Привет! Кто ты?"
```

Ответ печатается в консоль. Запрос и ответ сохраняются в
`days/01-minimal/logs/day01.json`.

## Структура

```text
days/
  01-minimal/          # минимальный пример: один запрос в Ollama
    config/            # модель, адрес Ollama, таймаут
    docs/              # ТЗ и как запускать
    prompts/           # системный промпт
    logs/              # JSON-лог запроса и ответа
    src/               # код дня
    pom.xml
docs/
  architecture.md      # устройство проекта и правила
  decisions.md         # зафиксированные решения
scripts/
  run.sh               # сборка и запуск
```

## Правила проекта

- День не зависит от `core`: `core` появится начиная со Дня 2.
- Каждый запуск Дня 1 перезаписывает свой лог: старый прогон удаляется,
  новый пишется атомарно.
- Время запроса измеряется только вокруг HTTP-вызова. Чтение конфига,
  очистка логов и запись результата в метрику не входят.
- Секреты (ключи API) в репозиторий не попадают: только env или
  `config/local.properties`, который в `.gitignore`.
- Финальная версия дня фиксируется локальным коммитом и тегом `day-NN`.
