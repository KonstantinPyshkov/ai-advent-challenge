# День 2. Порядок запуска

## 1. Проверка окружения

```bash
java -version
ollama --version
ollama list
```

Требуется модель `qwen3.5:35b-a3b`, предварительно загруженная в Ollama.

## 2. Проверка плана

```bash
./scripts/run.sh day2 --dry-run
```

Ожидаемый вывод: 6 вариантов, 3 повтора, 18 прогонов.

Пересобрать отчёт и консольный итог из уже сохранённого журнала, не обращаясь
к модели:

```bash
./scripts/run.sh day2 --report-only
```

## 3. Полный запуск

```bash
./scripts/run.sh day2
```

Скрипт собирает `core`, `days/day_02` и `cli`, затем запускает `lab.jar`.
Перед прогонами core:

1. ставит lock-файл;
2. очищает `logs/`, `reports/`, `conclusions/`;
3. проверяет, что каталоги пусты;
4. делает прогрев модели;
5. выполняет 18 прогонов;
6. пишет отчёт и вывод.

После этого в консоль выводится таблица формата со средними токенами и временем, а также краткий вывод.

## 4. Выходные файлы

```text
days/day_02/logs/runs.json
days/day_02/reports/report.md
days/day_02/reports/report.csv
days/day_02/conclusions/facts.md
days/day_02/conclusions/conclusion.md
```

Журнал обновляется после каждого прогона. Отчёт и вывод пересобираются из
журнала.

## 5. Ограничения запуска

`baseline` ограничен техническим потолком 8192 токена. Это ограничение
длины ответа, а не форматный контроль; часть baseline-прогонов может
завершиться по `length`.

## 6. Ограничение stop

Ollama 0.40.15 не применяет `stop` в `/api/chat` для проверенных моделей.
Параметр `stop=["}"]` отправляется в запросе, но для варианта `stop`
клиент дополнительно обрезает ответ по этому разделителю. Это отражено в
отчёте и в выводе; при смене версии Ollama поведение нужно перепроверить.

## 7. Повторный запуск

Повторный `./scripts/run.sh day2` удаляет предыдущие `logs/`, `reports/` и
`conclusions/`. Исходные данные, промпты, документация и конфигурация не
изменяются.

## 8. Диагностика

| Симптом | Причина | Действие |
|---|---|---|
| `Эксперимент уже выполняется` | Остался `.run.lock` | Удалить файл после проверки, что процесс не запущен |
| `HTTP 404: ...` | Модель не загружена | Проверить `ollama list` |
| Таймаут | Модель загружается или не отвечает | Проверить `ollama ps`, увеличить `llm.timeout-seconds` |
| `Схема не соблюдена` | Ответ синтаксически валиден, но структура другая | Смотреть `reports/report.md` и `checks.errors` в журнале |
| `Поля не совпали` | Модель ошиблась в фактах | Это ограничение знаний, не формата |
