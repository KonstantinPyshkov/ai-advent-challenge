# День 2. Сценарий видео

1. Показать ТЗ: один вопрос, шесть уровней контроля формата.
2. Показать `config/experiment.properties`, `prompts/question.md`,
   `prompts/format.md`, `data/schema.json`.
3. Запустить `./scripts/run.sh day2 --dry-run` и показать план: 6 вариантов,
   3 повтора, 18 прогонов.
4. Запустить `./scripts/run.sh day2`.
5. Показать прогресс, таблицу формата со средними токенами/временем и краткий вывод в консоли.
6. Открыть `reports/report.md`:
   - краткую сводку и таблицу результатов;
   - средние токены и время в основной таблице;
   - матрицу прогонов;
   - пример `max_tokens` — обрезанный JSON;
   - пример `json_mode` — валидный JSON без схемы;
   - пример `schema` — валидная схема с неверными значениями;
   - `baseline` и `stop` разобрать по сводке: JSON не разобран.
7. Открыть `conclusions/conclusion.md` и проговорить вывод.
8. Отдельно отметить ограничения: локальная модель без web-поиска,
   фактическая точность отделена от формата, `stop` эмулируется клиентом
   из-за поведения Ollama 0.40.15.
