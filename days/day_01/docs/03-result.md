## Запрос

```bash
./scripts/run.sh day1 "Перечисли три преимущества локального запуска LLM. Ответь тремя короткими пунктами."
```

## Ответ модели

> 1. **Снижение затрат на инфраструктуру**: Не нужно платить за серверы, сетевые подключения или облачные подписки.
> 2. **Полная приватность данных**: Локально обрабатываются ваши запросы, что исключает утечку информации в облако.
> 3. **Гибкость и контроль**: Вы сами выбираете модель, параметры и место хранения данных на своем устройстве.

## Метрики

| Метрика | Значение |
|---|---:|
| `timing.requestMs` | 661 мс |
| `timing.serverTotalMs` | 632 мс |
| `timing.loadMs` | 1 мс |
| `tokens.prompt` | 60 |
| `tokens.completion` | 87 |

Измерение `requestMs` охватывает только HTTP-вызов. Чтение конфигурации,
очистка журнала, разбор JSON и запись результата в метрику не входят.

Модель была загружена предыдущим запуском, поэтому `loadMs` равен 1 мс.
При первом запуске после простоя загрузка занимает заметно больше времени.
