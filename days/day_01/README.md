# День 1. Минимальный клиент к Ollama

## Назначение

Один запрос к локальной языковой модели, один ответ в консоль и один
JSON-журнал. Реализация не содержит истории диалога, стриминга,
веб-интерфейса и общего модуля `core`.

Модель: `qwen3.5:2b-mlx` — минимальная из трёх моделей проекта.

## Требования

- Java 21;
- Maven;
- Ollama;
- модель `qwen3.5:2b-mlx`.

Модель должна быть предварительно загружена в Ollama.

## Запуск

Из корня репозитория:

```bash
./scripts/run.sh "Перечисли три преимущества локального запуска LLM."
```

Прямой запуск:

```bash
mvn package
java -jar days/day_01/target/day01.jar "Перечисли три преимущества локального запуска LLM."
```

## Конфигурация

`config/day.properties`:

```properties
llm.base-url=http://127.0.0.1:11434
llm.model=qwen3.5:2b-mlx
llm.think=false
llm.timeout-seconds=300
```

Параметры запроса: `temperature=0`, `num_predict=1024`, `num_ctx=8192`.
Стриминг отключён, режим рассуждения отключён.

Флаги командной строки:

```text
--model M        переопределить модель
--base-url URL   переопределить адрес Ollama
-h, --help       справка
```

## Журнал выполнения

Результат каждого запуска сохраняется в `logs/day01.json`:

- параметры запроса;
- сообщения `system` и `user`;
- ответ модели;
- количество токенов;
- время HTTP-вызова, серверное время и время загрузки модели;
- статус `success` или `error`.

Перед новым запуском предыдущий журнал удаляется. При ошибке формируется
журнал со `status: "error"` и текстом ошибки.

## Метрики

`timing.requestMs` — время от отправки HTTP-запроса до получения тела
ответа. Чтение конфигурации, очистка журнала, разбор JSON и запись
результата в это время не входят.

`timing.loadMs` — время загрузки модели по данным Ollama. При первом
запуске после простоя значение может быть значительным.
