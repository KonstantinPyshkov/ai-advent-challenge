# День 5. Версии моделей

## Назначение

Семь задач с известными ответами решаются на четырёх моделях разных
размеров и провайдеров. Сравниваются правильность, время, токены,
стоимость и ресурсоёмкость.

## Модели

| Модель | Провайдер | Ресурс | Стоимость |
|---|---|---|---|
| `qwen3.5:9b-mlx` | Ollama | ~8 ГБ | — |
| `deepseek-flash` | DeepSeek API | облако | платно |
| `qwen3.5:35b-a3b` | Ollama | ~20 ГБ | — |
| `deepseek-v4-pro` | DeepSeek API | облако | платно |

## Параметры

- 7 задач;
- 1 прогон на модель × задачу;
- 28 прогонов;
- `temperature=0`;
- `think=false`;
- `maxPredict=2048`;
- `numCtx=8192`.

Параметры одинаковые у всех моделей, чтобы сравнение было честным.

## Запуск

Интерактивно:

```bash
./scripts/run.sh
# выбрать 5 или 05
```

Прямой запуск:

```bash
./scripts/run.sh day5
```

Проверка плана:

```bash
./scripts/run.sh day5 --dry-run
```

Пересборка отчёта:

```bash
./scripts/run.sh day5 --report-only
```

Для DeepSeek нужен ключ: `DEEPSEEK_API_KEY` или macOS Keychain.

## Артефакты

```text
logs/runs.json              все 28 прогонов
reports/report.md           таблица, матрица, примеры
reports/report.csv          сводка
conclusions/facts.md        метрики
conclusions/conclusion.md   вывод
```

## Ограничения

- Один прогон на комбинацию, без повторов.
- Стоимость DeepSeek считается по cache miss и тарифу off-peak/peak.
- Локальные модели бесплатны; их стоимость в таблице — `—`.
- Время — только HTTP-вызов; модели прогреваются до прогонов.
