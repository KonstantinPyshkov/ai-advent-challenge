# День 5. Дизайн эксперимента

## Модели

| id | Провайдер | Роль | Ресурс |
|---|---|---|---|
| `qwen3.5:9b-mlx` | Ollama | маленькая локальная | ~8 ГБ |
| `deepseek-flash` | DeepSeek | средняя API | облако |
| `qwen3.5:35b-a3b` | Ollama | крупная локальная | ~20 ГБ |

Порядок фиксирован. Модель в меню не выбирается: День 5 сам прогоняет
все четыре.

## Задачи

| id | Ответ | Тип |
|---|---|---|
| `arith-mult` | 391 | число |
| `logic-cats` | нет | нормализованный |
| `algo-sum` | 10 | число |
| `date-2030` | вторник | нормализованный |
| `data-avg` | 100 | число |
| `div7` | 128 | число |
| `digit5` | 136 | число |

`div7` — сколько трёхзначных чисел делятся на 7.
`digit5` — сколько трёхзначных чисел с разными цифрами делятся на 5.
Ответы проверены перебором.

## Справедливость

- `temperature=0` для всех;
- `think=false` для всех;
- одинаковый системный промпт и маркер `ОТВЕТ:`;
- `maxPredict=2048`, `numCtx=8192`;
- один прогон на модель × задачу;
- все модели прогреваются до начала замеров.

## Метрики

- `Верных` — точное совпадение с эталоном;
- `Формат` — найден маркер `ОТВЕТ:`;
- `Время` — сумма / среднее по HTTP-вызовам;
- `Токены` — prompt / completion / total;
- `Стоимость` — для DeepSeek за все прогоны, cache miss, off-peak / peak;
- `Ресурс` — локальная память или API.

## Стоимость

Официальный прайс DeepSeek, $ за 1M токенов:

| Модель | input off/peak | output off/peak |
|---|---|---|
| `deepseek-flash` | 0.15 / 0.30 | 0.60 / 1.20 |
| `deepseek-v4-pro` | 0.66 / 1.32 | 1.98 / 3.96 |

Считается cache miss: `prompt × input + completion × output`.
Курс для отчёта: **1 USD = 82.14 ₽** (`experiment.usd-rub`).
Локальные модели — `—`.

## Ограничения

- 7 задач — небольшая выборка;
- один прогон, без оценки разброса;
- стоимость зависит от peak/off-peak и фактического кэширования;
- качество ответа оценивается только по эталону, без LLM-судьи.
