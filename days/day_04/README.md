# День 4. Температура

## Назначение

Сравнить три значения `temperature` на двух типах задач:

- задача с одним правильным ответом;
- генерация названий.

Каждая комбинация выполняется 5 раз. Сравниваются правильность, формат,
разнообразие, токены и время.

## Модель

`qwen3.5:9b-mlx`, `think=false`.

Модель фиксирована: в меню Дня 4 выбор модели не запрашивается. Это нужно,
чтобы различие результатов объяснялось температурой, а не сменой модели.

## Матрица

- `temperature`: `0.0`, `0.7`, `1.2`;
- 2 задачи;
- 5 повторов;
- **30 прогонов**.

## Запуск

Интерактивно:

```bash
./scripts/run.sh
# выбрать 4 или 04
```

Прямой запуск:

```bash
./scripts/run.sh day4
```

Проверка плана без запросов:

```bash
./scripts/run.sh day4 --dry-run
```

Пересборка отчёта из сохранённого журнала:

```bash
./scripts/run.sh day4 --report-only
```

## Артефакты

```text
logs/runs.json              все 30 прогонов
reports/report.md           таблица, примеры, ограничения
reports/report.csv          сводка для таблиц
conclusions/facts.md        метрики
conclusions/conclusion.md   вывод по правилам и данным
```

## Ограничения

- Одна задача каждого типа.
- Качество названий оценивается вручную; автоматически проверяются формат
  и разнообразие.
- `temperature=0` не гарантирует одинаковые ответы; это проверяется
  фактически, а не предполагается.
