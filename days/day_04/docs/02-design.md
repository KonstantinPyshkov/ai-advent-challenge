# День 4. Дизайн эксперимента

## Гипотеза

1. `temperature=0` должен давать более стабильные ответы, но на локальной
   модели это не гарантировано.
2. `0.7` — компромисс: приемлемая точность и умеренное разнообразие.
3. `1.2` увеличивает разнообразие генерации, но повышает риск ошибок и
   поломки формата.
4. На задаче с одним ответом разнообразие скорее вредит; на генерации —
   помогает.

## Задачи

| id | Тип | Проверка |
|---|---|---|
| `answer-crayons` | один правильный ответ | `ОТВЕТ: 352`, число |
| `generation-coffee` | генерация | 5 строк без нумерации |

### Answer

> В магазине 17 коробок по 23 карандаша. 39 карандашей продали. Сколько
> карандашей осталось?

Эталон: **352**. Ответ должен заканчиваться строкой `ОТВЕТ: <число>`.

### Generation

> Придумай 5 названий для кофейни рядом с метро. Каждое название — с новой
> строки, без нумерации и пояснений.

Проверяется формат: ровно 5 непустых строк, без нумерации и маркеров списка.
Качество названий оценивается вручную.

## Матрица

- 3 температуры: `0.0`, `0.7`, `1.2`;
- 2 задачи;
- 5 повторов;
- 30 прогонов;
- 30 API-вызовов (по одному на прогон).

## Параметры

- модель `qwen3.5:9b-mlx`;
- `think=false`;
- `maxPredict=1024`;
- `numCtx=8192`;
- `temperature` — 0.0 / 0.7 / 1.2.

## Метрики

- `Верных` — для answer: сколько ответов совпало с 352;
- `Формат` — маркер `ОТВЕТ:` для answer, 5 строк для generation;
- `Уникальных` — для answer: уникальные ответы из 5; для generation:
  уникальные названия / всего названий;
- `Ср. сходство` — среднее попарное Jaccard-сходство слов;
- `avg токены`, `avg время`.

## Проверка `temperature=0`

Считается число уникальных нормализованных ответов на 5 прогонов:

- `1/5` — ответы одинаковые;
- больше `1/5` — одинаковость не гарантирована.

## Ограничения

- по одной задаче каждого типа;
- генерация оценивается по формату и разнообразию, не по «правильности»;
- один локальный провайдер и одна модель;
- выводы ограничены этим набором задач.
